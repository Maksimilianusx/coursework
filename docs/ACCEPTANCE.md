Для повторения HTTP-проверок: `python scripts/acceptance_http.py --secrets-dir secrets --output evidence/http-acceptance.json`. Для компонентных тестов: `docker run --rm -v "$PWD/tests:/tests:ro" course/api:local python -m unittest discover -s /tests -v` (Bash).
